# Employee app reference screens

Seven screenshots of the live Kapsons employee app, supplied 2026-09-02. **More are coming** —
the Menu screen is cut off below "Apply Gate Pass", so at least one further section exists that
has not been seen yet.

The images are here, copied from `scopedocs/app2/` (originals `1.png`–`7.png`). Every
reference in [employee-app-catalogue.md](../employee-app-catalogue.md) points at these paths.

| File | Screen |
|---|---|
| `E01-menu.png` | Menu — My Profile / Leave Management / Gate Pass sections |
| `E02-employee-profile.png` | Employee Profile bottom sheet |
| `E03-salary-details.png` | Salary Details bottom sheet |
| `E04-leave-history.png` | Leave History bottom sheet |
| `E05-home.png` | Home — identity card, KPI grid, Interview Schedule |
| `E06-attendance.png` | Attendance — stat tiles and recent attendance |
| `E07-attendance-full-month.png` | Full Month Attendance — calendar and export |

The catalogue transcribes every value visible in these screens, so it stands on its own if the
files are lost. It is not a substitute for the images when checking layout and colour.

## Relationship to the other reference set

`../screen-references/` holds nine screenshots of the **HR/recruiter** app (dashboard, manage
jobs, applicants, interviews). This set is the **employee** app. They are different products
sharing one backend, and the widget vocabularies differ — see §1 of the catalogue.
